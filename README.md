# 사교원 사회혁신팀러닝

팀러닝을 하는 팀을 위한 자문·컨설팅 사이트. 사회혁신교육원 사회적협동조합 운영.

## 페이지 구성
| 파일 | 역할 |
|---|---|
| `index.html` | 소개 + 팀 등록(전용 링크 발급) |
| `team.html?t=토큰` | 팀 공간 — 질문·답변 / 계획안·보완 / 자료조사 / 최종보고 |
| `report.html?t=토큰` | 최종 보고페이지 (인쇄/PDF 저장 가능) |
| `admin.html` | 관리자 — 질문·계획안·조사요청 처리, 팀 목록, 보고서 발행 |
| `db-schema.sql` | Supabase 스키마 (`tl_` 접두사, 여러 번 실행해도 안전) |

## 구조
- **DB**: academy·망남과 같은 Supabase 프로젝트, `tl_` 접두사 테이블 5개
- **팀 접근**: 로그인 없음 — 등록 시 발급되는 토큰 링크로만 접근 (RPC 함수 경유, 테이블 직접 접근은 RLS로 차단)
- **관리자**: Supabase Auth 로그인 + `is_admin()` (academy와 공유)
- **답변 흐름**: 팀 제출 → 관리자가 클로드코드(데카)와 답변 초안 작성 → 추가 조언 입력 → 게시 → 팀 공간에 표시

## 상태 값
- 질문: `대기중` → `답변완료` / 계획안: `대기중` → `보완완료` / 조사: `대기중` → `게시완료`
